# igz_solids 1.0.0

First release of **igz_solids**, a toolbar extension for
[IngeTrazo](https://github.com/ingelibre/ingetrazo) that creates parametric
3D solids. Port of the *ArkZ* SketchUp Ruby solid tools to IngeTrazo's Python
plugin API.

## What you get

- **14 toolbar buttons**, mirrored in **Extensions ▸ Solids**:
  Box, Wedge, Capsule, Cylinder, Tube, Sphere, Domus, Wedge (spherical
  segment), Cone, Pyramid, Geodesic Sphere, Helix, Prism and Torus.
- **A parameter dialog per solid**, in metres, plus two placement modes:
  *At the cursor (click)* — with a live wireframe preview — or
  *At the origin (0, 0, 0)*.
- **Every solid is its own Group**, named after the button and selected on
  creation. It has its own mesh, so it never welds to the model: it is easy to
  select, move and edit, and it lands in one undo step.
- **Watertight and correctly wound**, with softened curved seams and crisp
  flat rims — the IngeTrazo equivalent of SketchUp's soft + smooth.
- **Geodesic sphere** from a tetrahedron, octahedron or icosahedron
  (frequency 0–4) **and a Football (soccer ball)** — the exact truncated
  icosahedron (12 pentagons + 20 hexagons).
- **Four languages**, following IngeTrazo's UI language: English (source),
  Spanish, Brazilian Portuguese and Italian.
- **Themed SVG icons** for the dark and the light interface.

## Requirements

- **IngeTrazo 0.5.7** or later.
- Windows or Linux. No extra dependencies (`pip` not needed).

## Installation

In IngeTrazo: **Extensions ▸ Open plugins folder**, drop the `igz_solids`
folder there and restart. Or install it from the extension catalog at
<https://ingetrazo.com/extensiones>.

## Archive

`igz_solids.zip` unpacks to a single top-level `igz_solids/` folder, which
installs into `<plugins>/igz_solids/`.

```
igz_solids/
├── __init__.py   _core.py   tb_*.py   tb_list.txt
├── i18n/         # en, es, pt-BR, it
├── icons/        # tb_<name>.svg and tb_<name>_light.svg
└── LICENSE  README.md  README_ptBR.md  THIRD-PARTY.md
```
